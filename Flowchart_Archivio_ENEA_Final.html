🔑 Punti Chiave - Archiviabilità

  • CANCELLATA: Sempre già in archivio (spostata automaticamente alla cancellazione)
  • ANNULLATA: Archiviabile quando dataRichiestaConclusa != null
  • Stati finali (Approvata/Non fattibile/Gestita): Archiviabili solo quando dataRichiestaConclusa <= oggi
  • Trasporto futuro: Anche se approvata, NON archiviabile finché il trasporto non è avvenuto
  • Stati intermedi: Mai archiviabili (Bozza, In valutazione, Domande richiedente)
SELECT * FROM richieste WHERE isArchived = false AND ( stato = 'Annullata' OR stato = 'Cancellata' OR ( stato IN ('Approvata', 'Non fattibile', 'Gestita con mezzo reparto') AND dataRichiestaConclusa <= CURRENT_DATE ) )

⚠️ Punti Critici - Cancellazione Admin

  • Permessi ristretti: Solo Remadife (tutte) e Configuratore Reparto (proprio reparto)
  • Doppia conferma: Checkbox obbligatorio + motivazione testuale obbligatoria
  • Pulsante disabilitato: Finché checkbox non è checked e motivazione non compilata
  • Transazione atomica: Update stato + audit log insieme (rollback su errore)
  • Archiviazione automatica: La richiesta cancellata va direttamente in archivio (isArchived=true)
  • Audit trail: Ogni cancellazione loggata con chi, quando, cosa, perché, IP, stato precedente
  • Irreversibile: Nessun ripristino possibile (stato finale)
  • Visibilità archivio: Badge rosso scuro "CANCELLATA" con dettagli cancellazione
-- UPDATE transazionale BEGIN TRANSACTION; UPDATE richieste SET stato = 'Cancellata', deletedBy = 'userId_admin', deletedDate = NOW(), motivazioneCancellazione = 'Richiesta test - formazione utenti', isArchived = true, archivedDate = NOW(), archivedBy = 'userId_admin' WHERE id = 157; INSERT INTO audit_log (timestamp, action, userId, requestId, previousState, reason, ipAddress) VALUES (NOW(), 'DELETE_REQUEST', 'userId_admin', 157, 'Bozza', 'Richiesta test...', '10.0.0.1'); COMMIT;

🔑 Punti Chiave - Job Automatico

  • Esecuzione: Ogni notte alle 02:00 (orario basso carico)
  • Soglia temporale: 30 giorni dalla conclusione (configurabile)
  • Due query separate: Annullate + Completate, poi merge
  • Double-check: Ri-verifica archiviabilità prima di update (race condition)
  • Contatori per stato: Traccia breakdown archiviazioni per tipo
  • Report email opzionale: Notifica admin del numero richieste archiviate
  • archivedBy = 'SYSTEM': Distinguibile dalle archiviazioni manuali
-- Query Annullate (30+ giorni concluse) SELECT * FROM richieste WHERE stato = 'Annullata' AND isArchived = false AND dataRichiestaConclusa < (NOW() - INTERVAL 30 DAY); -- Query Completate (30+ giorni dal trasporto) SELECT * FROM richieste WHERE stato IN ('Approvata', 'Non fattibile', 'Gestita con mezzo reparto') AND isArchived = false AND dataRichiestaConclusa < (NOW() - INTERVAL 30 DAY);

🔑 Punti Chiave - Visualizzazione Archivio

  • 5 stati diversi: Annullata, Approvata, Non fattibile, Gestita, Cancellata
  • Badge colorati distintivi: Ogni stato ha colore specifico
  • Filtro stato: Dropdown con tutte e 5 le opzioni
  • Righe espandibili: Click per vedere dettagli completi in sola lettura
  • Dettagli specifici per stato: Cancellata mostra chi/quando/perché, Approvata mostra storico, etc.
  • Paginazione: 50 record per pagina (performance)
  • Nessuna azione modificante: Solo consultazione, nessun edit/delete/ripristino
📋 Riepilogo Logiche Chiave

✅ Archiviabile

  • Annullata con data conclusa
  • Approvata con trasporto passato
  • Non fattibile con data passata
  • Gestita reparto con trasporto completato
  • Cancellata (sempre, già in archivio)

❌ NON Archiviabile

  • Approvata con trasporto futuro
  • Bozza (stato intermedio)
  • In Valutazione (stato intermedio)
  • Domande al Richiedente (stato intermedio)
  • Valutazione presso Segreteria (stato intermedio)

🔐 Permessi Cancellazione

  • Remadife: ✓ Qualsiasi richiesta
  • Configuratore Reparto: ✓ Proprio reparto
  • Segreteria: ✗ No
  • Approvatori: ✗ No
  • Richiedente: ✗ No (solo annullare)

📊 Stati Archivio (5)

  • 🚫 Annullata - Grigio
  • ✓ Approvata - Verde
  • ❌ Non fattibile - Rosso chiaro
  • ℹ️ Gestita reparto - Azzurro
  • 🗑️ Cancellata - Rosso scuro

⚠️ Differenza Critica: Archiviare vs Cancellare

📦 ARCHIVIARE

  • Richieste completate/annullate
  • Manuale (utente) o automatica (job)
  • Sposta in archivio storico
  • Disponibile a tutti i ruoli
  • Nessuna motivazione richiesta

🗑️ CANCELLARE

  • Qualsiasi richiesta (anche intermedia)
  • Solo manuale (admin)
  • Marca come "Cancellata" + archivia auto
  • Solo Remadife/Configuratore
  • Motivazione obbligatoria + audit log
